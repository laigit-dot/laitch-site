Desktop app for Windows

Laitch

Laitch is a personal desktop assistant that helps one person apply to jobs: it keeps a list of openings, tailors a resume for each, and fills in application forms in a browser on the user's own computer.

Why Laitch asks for Gmail access

Many job sites email a one-time code or a confirmation link before an application can continue. When the user connects their Gmail account, Laitch reads new messages in that mailbox, read-only, to find that code or link and enter it on the site that sent it. Laitch never sends, deletes, moves, labels or changes email.

Everything happens on the user's own Windows computer. Laitch has no servers, and nothing from the mailbox is sent to the developer or to anyone else.
